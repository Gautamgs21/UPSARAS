How this form works & what gets computed
  • Basic Details. Licensee Name and Financial Year. The FY drives the default quarter dates in all quarterly tables — changing it re-fits every single-period quarter in Tables B and Backbone A.
  • Spectrum Types. Tick the spectrum types available (choosing a Technology in the holdings table ticks its type automatically). Ticking GSM MWA, GSM MWB, E-Band or Other adds a dedicated row-block for that type inside the Backbone Spectrum table.
  • Access Spectrum Rates (sidebar). Auction Year / Technology / Frequency auto-fill from the GSM Access rows. The Rate you type is written into Q1–Q4 of that row in Table A. When Spectrum Sharing Rate Added to Shared Band is ticked, each shared row's rate is increased by 0.50 % here (and in Q1–Q4); unticking removes it.
  • Spectrum Holdings of M/s … Rows where Is Shared = Yes are shown in bold dark blue. Dates accept pastes in dd-mm-yyyy, dd/mm/yyyy, yyyy-mm-dd, ddmmyyyy or Excel serial and are normalised to dd-mm-yyyy.
  • A. SUC Rate for GSM Access Spectrum. A checkbox under this table toggles Spectrum Sharing Rate Added to Shared Band:
    • Checked — 0.50 % is added to each shared row's rate (visible in the sidebar) and is therefore already inside Q1–Q4.
    • Unchecked — the rows keep their base rates; the individual SUC Rates are weighted-averaged for the quarter and 0.50 % is then added to that quarterly Weighted Average in Table B.
    • Either way, the 0.50 % only applies when a GSM Access row flagged Shared is actually active in the period being calculated. Your typed base rates are never overwritten — ticking and unticking is fully reversible.
  • B. Weighted Average of SUC Rate for the Quarter. Auto-computed as ROUNDUP(Σ(Quantum2016 × Qn) / Σ(Quantum2016), 4) — only counting active rows. Every From / To cell is checked against its quarter's FY-derived range; inconsistent dates are shown bold red.
  • II. Calculation of SUC Rate for GSM MWA/MWB Spectrum. For each period enter the total active Quantum of Spectrum (MHz) and pick the Order Applicable (2002 or 2006). The SUC Rate is auto-computed: 2002 order = base slab + 0.05 % per 28 MHz or part (MWA base = 112 MHz @ 0.25 %; MWB base = 56 MHz @ 0.10 %); 2006 order = cumulative table per 56 MHz carrier (up to 6 carriers). Every From / To cell is checked against its quarter's FY range; inconsistent dates are shown bold red.
  • III. Summary. MAIN column mirrors Table B's Weighted Average; each backbone column mirrors the corresponding type's Weighted Average.
  • Tabs. The tab bar above the form holds one independent assessment per tab — each with its own Basic Details, Spectrum Types, holdings, Q1–Q4 periods, backbone tables and remarks. Use + to add a tab, × on a tab to close it. The active tab is remembered when you reload.
  • Persistence. Everything (every tab) is remembered in your browser. RESET ALL wipes the saved cache and returns a blank single-tab form.
All values are stored exactly as typed. Calculations use full precision internally.
